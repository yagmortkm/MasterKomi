# MasterKomi
<h2>Описание</h2>
Это единый агрегатор и витрина мастер-классов. Пользователь может зарегестрировать аккаунт, войти в личный кабинет, записаться на мастеркласс, посмотреть календарь событий. Тажке, возможна фильтрация по направлениям (творчество, спорт, IT), городам и сортировка по времени.

<h2>Пояснительная записка</h2>
<b>Название:</b> МастерКоми<br>
<b>Автор проекта:</b> Тимушев Георгий Дмитриевич<br>
<b>Описание идеи:</b> Создание инструмента, позволяющего желающим записаться на конкурсы и мастерклассы в Республике Коми. Предоставляется возможность записи на мероприятие, добавление мероприятий. Также возможна фильтрация по направлениям, городам.<br>
<b>Описание реализации, технологии:</b> В основе проекта используется данных с таблицами. Программа написана на языке программировния Python. Взаимодействия со страницами происходят с помощью Flask, в том числе, реализованы формы с помощью flask-wtf и wtforms. Были использованы методы POST и GET запросов.<br>
<b>Необходимые библиотеки:</b> flask, flask_wtf, wtforms, sqlalchemy, datetime, werkzeug.
